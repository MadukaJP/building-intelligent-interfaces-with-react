# React Class Starter — Setup Guide

Follow these steps to get the class project running on your machine.

## Step 1: Create a Project Folder
- Create a new folder on your computer named `react-class-project`
- Open **VS Code**
- Click **File → Open Folder**, then select the `react-class-project` folder

## Step 2: Open the Terminal
- In VS Code, go to **Terminal → New Terminal**
- Clone the class repository by running:
```bash
git clone https://github.com/MadukaJP/kickdrop.git
```

## Step 3: Move Into the Project Folder
```bash
cd kickdrop
```

## Step 4: Install Dependencies
```bash
npm install
```
This downloads all the packages the project needs to run.

## Step 5: Start the Development Server
```bash
npm run dev
```
This will start the app locally — check your terminal for a link (usually `http://localhost:5173` or similar) and open it in your browser.

---

**Note:** Make sure `git` and `Node.js` (with `npm`) are installed before Step 2 and Step 4 — students can check by running `git --version` and `node -v` in the terminal.
