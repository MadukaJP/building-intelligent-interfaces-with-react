# Session 1 Assignment — Favorite Movie Card

**Time estimate:** 20–30 minutes
**New project:** yes — a fresh Vite + React app, separate from KickDrop.

## Task

1. Create a new project: `npm create vite@latest movie-card -- --template react`
2. In `App.jsx`, replace the default content with one hardcoded "movie
   card" showing:
   - A movie title
   - The release year
   - A rating (e.g. out of 10)
3. Get it running with `npm run dev` and confirm it renders correctly.

No components, no props yet — just get one static card on the screen,
the same way you did with the first sneaker card in class.

## What "done" looks like

A running local dev server showing your movie's title, year, and rating,
inside some kind of container `<div>`.

## Before Session 2: a quick look ahead

Session 2 is about **components** — breaking one big function into
smaller, reusable pieces. Before class, try this:

- Look at your movie card's JSX. If you had to build a *second*, different
  movie card right now, what would you have to copy-paste?
- Search "React component" (MDN, React's own docs, or a quick video) and
  see if you can find one sentence that explains what a component is *in
  your own words*. Bring it to class — we'll compare notes.

You don't need to build anything for this part — just come with a guess.
