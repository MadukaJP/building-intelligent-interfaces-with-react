# Session 5 Assignment — Like Counter

**Time estimate:** 20–30 minutes
**New project:** yes — a fresh Vite + React app.

## Task

1. Create a new project: `npm create vite@latest like-counter -- --template react`
2. Show a single photo placeholder (a plain `<div>` is fine, no real image
   needed) with a heart/like button beneath it.
3. Clicking the button increases a like count shown on screen, using
   `useState` — no cart, no KickDrop concepts, just one button and one
   number.

## What "done" looks like

A number on screen that increases by one every time you click the button,
starting from 0.
